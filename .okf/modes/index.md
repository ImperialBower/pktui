# Modes

pktui runs in one of four modes, selected at startup by CLI subcommand.

* [Play](play.md) - one human at seat 0 vs eight bots.
* [Arena](arena.md) - all bots, watch-only; user controls speed only.
* [Replay](replay.md) - step through a saved YAML hand collection (read-only).
* [Spectate](spectate.md) - read-only viewer of a live pkdealer table over gRPC.
